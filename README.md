# Hyundai Samarkand · Маркетинговый дашборд

Веб-версия маркетингового дашборда. Данные загружаются при открытии из Google-таблицы «Hundai Dashboard»
через Apps Script «Hyundai Dashboard API» и показываются только после ввода пароля.

- `index.html` — вся страница: стиль Hyundai, расчёты, графики, вход.
- Пароль хранится в скрипте (константа `KEY`). Смена пароля: поменять `KEY` → Развернуть → Управление развертываниями → Изменить → Новая версия.
